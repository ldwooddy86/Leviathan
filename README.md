# Leviathan

Marketing intelligence atlases, the unified console that holds them, and the browser app that carries the console.

| Path | What it is |
|---|---|
| `leviathan/` | **Leviathan**, the unified console: OmegaWeapon and the Hit Board at the core, fourteen industry atlases in three wings (the Louisiana editions of Probable Cause and Contraflow, the DFW Thermal Debt Atlas and the Dental Divide Atlas among them, plus the Termination Exposure Atlas), the Convergence map and the Agency Field. One file with everything, `leviathan/Leviathan-full.html` (62 MB), or the split edition in three files under 50 MB each, opened from `leviathan/Leviathan.html`. See `leviathan/README.md`. |
| `chrome-app/` | The **Leviathan browser app** (Chrome, Edge, Brave): the console above as an extension. A launcher popup with the three console views, the wings and their atlases, recent atlases and a search over atlases and modules; the `lev` address bar keyword; `Ctrl+Shift+L`; bookmarkable routes (`app.html#dental.paid`). The console runs as a sandboxed extension page with a `postMessage` bridge in place of the direct parent calls the atlases make; `chrome-app/console/` is the split edition from `leviathan/` plus six anchored one line patches, regenerated by `node build.mjs`. See `chrome-app/README.md`. |
| `dental-divide-atlas.html` | The Dental Divide Atlas, the dental market companion (single file). |
| `toothandnail.skill` | The Tooth and Nail skill card: the Dental Divide method packed for Claude. |

## Load the browser app

1. `chrome://extensions` → Developer mode → **Load unpacked** → choose `chrome-app/`. The console opens in a tab on the first install.
2. Pin the icon. The popup is the launcher; `Ctrl+Shift+L` (`Command+Shift+L` on a Mac) opens the console or brings it forward; typing `lev` and an atlas, module or wing name in the address bar opens it.

After a new console build lands in `leviathan/`, run `cd chrome-app && node build.mjs` to regenerate `chrome-app/console/` and `registry.js` from it, then click Reload on the extensions page.

Tests: `cd chrome-app && node tests/run.mjs` (unit, no packages) and `node tests/e2e/run.mjs` (Playwright: `npm install` in `chrome-app/` first, then `npx playwright install chromium`; loads the extension into Chromium and drives the console, three atlases and the popup).
