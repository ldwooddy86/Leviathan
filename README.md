# Leviathan

Marketing intelligence atlases, the unified console that holds them, and the browser app that carries the console.

| Path | What it is |
|---|---|
| `leviathan/` | **Leviathan**, the unified console: OmegaWeapon and the Hit Board at the core, fourteen industry atlases in three wings (the Louisiana editions of Probable Cause and Contraflow, the DFW Thermal Debt Atlas and the Dental Divide Atlas among them, plus the Termination Exposure Atlas), the Convergence map and the Agency Field, and the **Résumé Forge**: Clapback's ATS résumé engine pointed at the Agency Radar's findings, so a résumé can be aimed at an agency's current gaps and the lines it sells. One file with everything, `leviathan/Leviathan-full.html` (63 MB, the Forge inline), or the split edition in three files under 50 MB each, opened from `leviathan/Leviathan.html` (the plain console, without the Forge; the browser app and the single file are built from it). See `leviathan/README.md`. |
| `chrome-app/` | The **Leviathan browser app** (Chrome, Edge, Brave): the console above as an extension. A launcher popup with the four console views (Command Deck, Convergence, Agency Field, Résumé Forge), the wings and their atlases, recent atlases and a search over atlases and modules; the `lev` address bar keyword; `Ctrl+Shift+L`; bookmarkable routes (`app.html#dental.paid`). The console runs as a sandboxed extension page with a `postMessage` bridge in place of the direct parent calls the atlases make; `chrome-app/console/` is the split edition from `leviathan/` plus thirteen anchored one line patches and the Forge scripts beside it, regenerated by `node build.mjs`. See `chrome-app/README.md`. |
| `Leviathan-browser-app.zip` | The browser app zipped for anyone to install: download, unzip, then Load unpacked on the `leviathan-browser-app/` folder inside (steps below). Written by `node build.mjs --zip`. |
| `FEATURES.md` | Every feature of this build, dashboard by dashboard: the console, the Core, the fourteen atlases and their 228 modules, the Résumé Forge, the browser app, the editions. |
| `dental-divide-atlas.html` | The Dental Divide Atlas, the dental market companion (single file). |
| `toothandnail.skill` | The Tooth and Nail skill card: the Dental Divide method packed for Claude. |

## Load the browser app

From the zip, no checkout needed:

1. Download `Leviathan-browser-app.zip` (open it on GitHub and use the download button) and unzip it. It holds one folder, `leviathan-browser-app/`.
2. `chrome://extensions` (Edge: `edge://extensions`, Brave: `brave://extensions`) → turn on **Developer mode** → **Load unpacked** → choose that `leviathan-browser-app/` folder. The console opens in a tab on the first install.

From a checkout:

1. `chrome://extensions` → Developer mode → **Load unpacked** → choose `chrome-app/`. The console opens in a tab on the first install.
2. Pin the icon. The popup is the launcher; `Ctrl+Shift+L` (`Command+Shift+L` on a Mac) opens the console or brings it forward; typing `lev` and an atlas, module or wing name in the address bar opens it.

After a new console build lands in `leviathan/`, run `cd chrome-app && node build.mjs --full --zip ../Leviathan-browser-app.zip` to regenerate `chrome-app/console/` and `registry.js` from it, rewrite the single file edition `leviathan/Leviathan-full.html` in place with the Forge inline, and rewrite the zip; then click Reload on the extensions page.

Tests: `cd chrome-app && node tests/run.mjs` (unit, no packages: the patches, the bridge and store, the findings extraction, the Résumé Forge engine, the withheld-name scan, the single file edition) and `node tests/e2e/run.mjs` (Playwright: `npm install` in `chrome-app/` first, then `npx playwright install chromium`; loads the extension into Chromium and drives the console, four atlases, the Résumé Forge and the popup).
