Every other module estimates. This one measures. Connect the business's own ad and social accounts, or drop in the reports they export, and the atlas reads what the campaigns actually did: spend, clicks, leads and calls by service line, by hour of the day, by ZIP, and against the month's plan. Then, with one click, the observed cost per click, conversion rate and lead costs replace the assumptions in the service line model, and the Weather Desk's hour by hour plan runs on the account's real hours.

Sign in connections need the browser app, because a file has no registered redirect address. Pasted tokens work here where the provider allows page calls (Meta does, most Google APIs do); Microsoft and LinkedIn refuse calls from a file and need the app. Everything typed below stays in this browser's storage for this file.

Where it runs. The page detects its host: the Chrome or Firefox browser app (extension runtime present), a downloaded file, or the Claude viewer. Sign in connections use the browser identity API and need the app; pasted tokens work wherever the provider allows page calls; imports work everywhere.

Connections. Google, Microsoft and LinkedIn use the authorization code flow (PKCE where the provider supports it) against the business's own OAuth client; Google refresh tokens keep the connection alive. Local Services Ads and YouTube reuse the Google token. Meta uses the token flow of Facebook Login for Business and, with the app secret, exchanges the one hour token for a 60 day token. TikTok opens its portal authorization page and exchanges the auth code with the app secret for a long lived token; there is no refresh, the token works until it is revoked. Tokens and credentials live in extension storage or this browser's local storage and never leave it.

Versions. Google Ads and Meta are probed at Test time: the first version in the list that answers (v25, v24, v23 for Google Ads; v27.0, v26.0, v25.0 for Graph) is remembered and used until the next Test. TikTok Business API v1.3, Local Services API v1, YouTube Analytics v2 and Data v3, Microsoft v13 and LinkedIn 202509 are fixed.

Pulls. Google Ads API (campaigns by day and by hour, geographic view by postal code); Local Services API (detailed lead reports and account reports under the manager account, with the Google Ads local_services_lead report as the fallback); YouTube Analytics (channel by day, top 25 videos named through the Data API, channel statistics) plus video and Demand Gen campaigns from Google Ads; Business Profile Performance; Meta Marketing API (ad set by day, campaign by hour of the advertiser time zone, region), Page and Instagram insights; TikTok integrated report at campaign level by day and by hour in 30 day windows; Microsoft Advertising Reporting (hourly campaign performance, zipped CSV unpacked in the page, folded into daily rows); LinkedIn adAnalytics by campaign and Page follower statistics.

Normalization. Every source becomes rows of date, hour, campaign, ad set, geography, impressions, clicks, spend, leads, calls, messages and conversions, tagged with a service line from the campaign name (desk token first, keywords second). Daily rows carry no hour; hourly rows are a separate kind so nothing counts twice. When the YouTube or LSA card has pulled its own rows, the Google pull's copies of those campaigns are dropped from the totals.

Feedback. Apply computes search CPC from Google and Microsoft rows, and per line the Google conversion rate (50 clicks and 3 leads minimum), Meta cost per lead and LSA cost per lead (3 leads minimum), and writes them into the service line model. The Weather Desk can run on the observed hour of day distribution (90 days of hourly rows, six blocks, rounded to 5%).

Imports. A CSV parser that handles quoted fields, a header finder that skips report preambles, and column maps for the Google Ads, Meta, TikTok Ads Manager, Microsoft, LSA, YouTube Studio, call tracking and generic formats; ZIPs are read from any postal code column.

The module carries no developer credentials of its own. Each provider needs an app or client created in the business's console and, for accounts outside that app's own business, the provider's review. The setup steps on each card are the shortest path; Meta in development mode, Google in testing mode and a TikTok app in its own Business Center connect the business's own accounts without review.

Google and LinkedIn issue a client secret for web clients, TikTok an app secret, and Meta an optional app secret for the 60 day exchange; they are stored here so the token exchange can run from the page. Anyone with this browser profile can read them. Clear tokens and the settings when the machine changes hands.

The Marketing API token has no expiry and no refresh; it stops when the authorization is revoked in the portal. The card keeps it until Disconnect. Reports run in 30 day windows because the API refuses longer ranges.

The Local Services API only answers for a manager account that holds the LSA account; the card asks for that manager ID. Lead timestamps are converted to the account's time zone for the hour chart.
